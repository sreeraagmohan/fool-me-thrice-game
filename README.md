# Fool Me Thrice 🕵️

A real-vs-fake news game about India. Swipe through claims and judge each one
**REAL** or **FAKE** — three wrong answers ends your run.

- **FAKE cards** are genuine misinformation that actually circulated, sourced from
  [PIB Fact Check](https://factcheck.pib.gov.in) (the Indian government's official
  debunking unit). No fake news is generated by AI.
- **REAL cards** are derived from official PIB press releases, rewritten into the
  same informal register so the pools aren't distinguishable by style.

## Architecture

```
@PIBFactCheck (X)  ─┐
PIB Sindoor page   ─┼─▶ harvest/harvest.py ──▶ Claude (Haiku 4.5) ──▶ Supabase
PIB press releases ─┘        (daily GitHub Actions cron)                 │
                                                                         ▼
                                          docs/ (GitHub Pages, vanilla JS) ──▶ 📱
```

- `harvest/harvest.py` — pulls both pools, normalizes them into ≤200-char claim
  cards with one-sentence reveal explanations via the Claude API, and upserts to
  Supabase keyed on `source_id` (idempotent; safe to re-run). Structural changes
  in the source pages fail the run loudly rather than writing garbage.
- `docs/` — dependency-free mobile-first frontend served by GitHub Pages. Reads
  cards through Supabase's REST API with the public key (read-only via RLS).
- `.github/workflows/harvest.yml` — daily cron at 03:00 UTC (08:30 IST), plus
  manual dispatch. Requires repo secrets `SUPABASE_URL`, `SUPABASE_SECRET_KEY`,
  `ANTHROPIC_API_KEY`.

## Database

One table (`cards`), RLS on, anon may `SELECT` active rows only:

```sql
create table public.cards (
  id          uuid primary key default gen_random_uuid(),
  source_id   text unique not null,   -- 'tweet:<id>' or 'pib:<prid>'
  verdict     text not null check (verdict in ('REAL','FAKE')),
  claim       text not null check (char_length(claim) <= 200),
  category    text not null,
  explanation text not null,
  source_url  text not null,
  source_date date,
  active      boolean not null default true,
  created_at  timestamptz not null default now()
);
```

To retire a bad card, set `active = false` — the frontend only serves active ones.

## Local development

```bash
pip install -r harvest/requirements.txt
python harvest/harvest.py --dry-run   # fetch + normalize, no writes
python harvest/harvest.py             # full run (needs .env)

# frontend
python -m http.server -d docs 8000
```

`.env` (gitignored): `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `ANTHROPIC_API_KEY`.
